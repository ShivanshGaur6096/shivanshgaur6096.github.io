# Implementation Plan: Hero Section Redesign

## Overview

Replace the existing parallax hero (LandingPage.js/LandingPage.css) with a modern, text-forward, animated hero section featuring an orchestrated entrance timeline, interactive subtitle shuffle game, inline social icons, and cinematic profile photo treatment. Built on the existing React 19 + Framer Motion 12.4 + react-intersection-observer stack, with fast-check added for property-based testing.

- Integration (task 7) is last to ensure all pieces work before wiring together
