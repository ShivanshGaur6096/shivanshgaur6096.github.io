## Design Principles to Reference (from audit)

These are qualities found in premium portfolio websites that we want to embody:

### What makes premium portfolios feel premium:
- Exceptional typography (large, confident, well-spaced)
- Intentional whitespace (not fear of empty space)
- Strong visual hierarchy (instantly clear what matters most)
- Restrained color (1–2 accents, not a rainbow)
- Smooth, purposeful motion (alive but not distracting)
- Consistent design tokens (everything feels like it belongs together)
- High-quality imagery (crisp, properly sized, intentionally placed)
- Confident copywriting (says less, means more)

### What makes portfolios feel generic:
- Bootstrap/Tailwind default styles unchanged
- Carousel for everything
- Generic gradient backgrounds
- Stock illustrations
- "Let's Connect! 🤝" style copy
- No personality in typography choices
- Inconsistent spacing
- Too many competing colors
- Effects for the sake of effects

### Trends to avoid:
- Excessive glassmorphism
- Bento grid layouts (already overdone)
- Cursor follower animations
- Text scramble/decode effects on every heading
- Gradient mesh backgrounds
- "Built with ❤️" footers
- 3D globe/earth animations (unless relevant)
- Overly complex SVG line animations

### Patterns worth considering:
- Subtle scroll-linked animations (reveals, parallax with restraint)
- Dark mode with intentional surface hierarchy
- Monospace accents for technical metadata
- Project cards that show the work, not just describe it
- Smooth theme transitions
- Strong editorial typography at large sizes
- Reduced motion as a first-class experience
